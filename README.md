# Nexora - Campus Event & Club Management Platform
## 📌 About the Project

A mobile application for managing university events and clubs.
Students can discover events, RSVP, receive QR tickets, and check in to events.

## ✨ Features
- Student registration and login
- Browse campus events
- Event search and filtering
- Event RSVP
- QR ticket generation
- QR code event check-in
- Club event management
- Admin event approval
- Attendance tracking
- Event analytics

## 🛠️ Technologies Used
- Flutter
- Dart
- Python
- Django
- Django REST Framework
- PostgreSQL
- Git / GitHub
- Jira
- GitHub Actions
